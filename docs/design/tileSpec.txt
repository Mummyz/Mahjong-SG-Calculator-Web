═══ DOM ═══
`src/ui/components/Tile.tsx` keeps its structure. TWO additions only:

1. New prop `needed?: boolean` → emits `data-needed="true"` and takes the
   accessible name `t('tile.neededName', { tile: tileName(id) })`. Without
   this a screen reader hears the same name for "you have it" and "you still
   need it" on the one screen whose job is telling you what you are missing.
   Add key `tile.neededName` to `src/i18n/en.json`.
2. `.tile { isolation: isolate }` and `.tile__count { z-index: 2 }` — the
   badge now overhangs an `overflow: visible` tile.

`--tile-lip` is set purely in CSS from the existing `data-suit` / `data-h`
attributes. No new DOM for the lip.

GRID INVARIANT — a review lint, not a habit:
        (360 − 2·16 − (n−1)·8) / n ≥ 44
  n=5 → 59.2 ✓ (suits)   n=4 → 76 ✓ (honours, bonus)   n=7 → 40.0 ✗
Every tile grid uses `gap: var(--gap-row) var(--gap)` — 12px rows, 8px
columns. The extra 4px of row gap is the lip; without it lips collide with
the tile below. `.tray__group` padding goes 2px → 6px for the same reason.

Dark `--mj-gloss` is .06, not .10. At .10 the dark face lifts to #43534E and
萬 falls to 3.74:1 — a live AA failure in the winning pitch. At .06 the face
lifts to #36443E and the worst suit clears 4.71:1.

═══ THICKNESS + SHADOW — the whole direction is these two lines ═══
box-shadow: 0 4px 0 0 var(--tile-lip), 0 9px 14px -6px var(--mj-shadow);
.tile--mini  → 0 3px 0 0 var(--tile-lip), 0 6px 10px -5px var(--mj-shadow);
.tile:active:not([data-exhausted]) {
  transform: translateY(3px);
  box-shadow: 0 1px 0 0 var(--tile-lip), 0 3px 6px -4px var(--mj-shadow); }

EXACTLY ONE blurred shadow per tile. The lip is a 0-blur shadow and costs
nothing. This recipe is forbidden outside the tile, the primary button, the
fan medal and the wordmark tile.

LIPS — saturated, never tinted. A pale lip is the failure the owner already
rejected once ("reads as a soft underline, not thickness").
.tile[data-suit="m"] { --tile-lip: var(--mj-lip-m);   --suit: var(--mj-suit-m); }
.tile[data-suit="p"] { --tile-lip: var(--mj-lip-p);   --suit: var(--mj-suit-p); }
.tile[data-suit="s"] { --tile-lip: var(--mj-lip-s);   --suit: var(--mj-suit-s); }

.tile[data-h="F"]    { --tile-lip: var(--mj-lip-s); }
.tile--bonus         { --tile-lip: var(--mj-bonus-lip); }
Every lip clears 3:1 against BOTH its own face and the page ground, so the
tile always has an edge and always has a silhouette.

  The decorative inset frame uses ::before, NOT ::after — ::after is already

  cursor:not-allowed; no press transform.
  THIS BLOCK MUST COME AFTER the [data-h="P"] block in the stylesheet — the
  two ::after rules have identical specificity and source order decides.

GHOST  ( data-needed="true" — a tile you still need, prediction panel )
  Full-strength face, FULL-STRENGTH contents. No opacity anywhere: at 55%
  the coloured mark and the rule both fall below AA and two of the three
  mandated encodings die on the one screen built to name tiles.
  background:none; box-shadow:none; transform:none;
  outline: 2px dashed var(--mj-slot-edge); outline-offset:-2px;
  ::before { display:none }  /* no gloss on something you do not hold */
  plus a 14px "+" in var(--mj-collect) at bottom:4px; right:5px.
  ABSENCE OF WEIGHT, not absence of ink. Solid = you have it. Ghost = you
  need it. That one contrast is the whole visual grammar of prediction, and
  it is spoken as well as drawn via t('tile.neededName').
