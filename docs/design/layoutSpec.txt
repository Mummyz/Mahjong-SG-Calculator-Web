═══ 1. THE GROUND — and the fix that makes it visible at all ═══
`.shell` currently paints an opaque `var(--mj-ground)` across the whole
viewport, so a gradient on `body` would never render. The gradient goes ON
THE SHELL:

  body  { background: var(--mj-ground-2); color: var(--mj-ink);
          font: 400 0.9375rem/1.55 var(--f-body); margin:0; }
  .shell{ max-width: var(--col); margin:0 auto; height:100dvh;
          display:flex; flex-direction:column;
          background: linear-gradient(180deg, var(--mj-ground) 0%,
                                              var(--mj-ground-2) 58%)
                      var(--mj-ground-2); }
  .scroll { flex:1; min-height:0; overflow-y:auto; overflow-x:clip;
            overscroll-behavior:contain; padding: 0 var(--pad) var(--pad); }

`height:100dvh` + `min-height:0` on `.scroll` stay exactly as they are — the
existing comment says they are load-bearing for the sticky suit tabs, and
they are. `overflow-x: clip` is the one addition: `overflow-y:auto` computes
overflow-x to `auto`, which is how a rotated wordmark tile becomes a
horizontal scrollbar. This app's cardinal sin, closed with one declaration.

There is NO decorative blob. The 300px peach radial is deleted — it is the
single most template-shaped element in the direction, and positioned at
`right:-80px` it was also the thing creating the horizontal scroll.

═══ 2. DEPTH — a closed exception list ═══
RAISED (4px hard coloured lip + 3px press travel): the tile, `.btn--primary`,
the fan medal, the wordmark tile. FOUR THINGS. Nothing else, ever.
FLAT: every card.
  .card { background: var(--mj-card); border-radius: var(--r-card);
          padding: var(--sp-4); border: 1px solid var(--mj-line);
          box-shadow: 0 1px 2px var(--mj-shadow-soft),
                      0 8px 20px -12px var(--mj-shadow); }
  Dark: keep the hairline, add `inset 0 1px 0 rgb(255 255 255/.06)`, drop the
  drop shadow.
  THE HAIRLINE SHIPS IN BOTH THEMES. White card on mint ground is 1.24:1;
  a 6%-alpha shadow is not structure on a phone at low brightness. The
  hairline is 2.17:1 on card and 1.98:1 on ground — visible, not heavy.
  `.slip` and `.chit` both become `.card`.
CARVED IN (inset, never raised): the hand rack, the segmented-control track,
  the stamp cell, the results total band, the empty tray slot.
  box-shadow: inset 0 2px 6px var(--mj-shadow-soft);

Every `border: 1px solid var(--mj-rule)` in app.css is deleted except the
card hairline. `--mj-r: 2px`, `--mj-gutter: 3px` and `.grid`'s
`background: var(--mj-grout)` + padding are deleted outright.

  · The seat glyph is promoted from a flat chip to a REAL WIND TILE drawn at

    in the ledger, with no cartoon.

  · SIGN AND COLOUR ARE COMPUTED RELATIVE TO THE READER'S SEAT, not to the
    payer. Money arriving at you: "+", `--mj-collect`. Money leaving you:
    "−", `--mj-pay`. A transfer between two other players: neutral
    `--mj-ink` with "→". On a night you won, the screen is green, because
    you won. The current code renders every other player's row as
    `formatMoney(-units)` with class `pay`, which paints a winning night red.
  · Zero rows go `--mj-disabled` and unsigned. The verb is always spelled
    out, so direction of money is never colour-only.
  · The `<table>`/`<tr>`/`<td>` structure STAYS. If rows become flex divs
